## Prompt

You are curating an AI news summary for a WhatsApp group. The audience is non-technical, so everything must be clear and accessible to anyone.

1. Read the history file `historico-noticias-ia.md` in the Marketing Refatorando project to see what news has already been sent in previous weeks. If the file doesn't exist, create it.
2. Find 5 notable AI news stories from the past week that haven't been sent before. Focus on developments that affect everyday life or are widely discussed.
3. Write the summary in a conversational, friendly tone — as if the user is speaking to the group. Avoid jargon; explain any technical terms in simple language.
4. Format: a brief intro line, then the 5 stories as short paragraphs (2–3 sentences each), each with a link.
5. After finalizing the summary, add a new section to `historico-noticias-ia.md` with the week's date and a list of the 5 stories (title and link), so you don't repeat them next time.

If you can't find 5 fresh stories, send what you have and note that the week was quiet.
